# 命理諮詢大師：目標與規劃 v0.1
日期：2026-10-04｜Owner 指定 repo：firekou/FutuneTeller

## 1. 目標與成果定義
建立一位具有穩定人格、會問問題、會查典籍、能解釋依據並協助整理行動的 AI 命理諮詢大師。典籍是知識來源，人格是互動方式，程式負責檢索與可重現的規則。
第一個有用成果：使用者輸入一個問題與所需資訊，在同一介面完成澄清、檢索、解讀、來源核對與追問。不是只交付一段扮演大師的文字。

定位為傳統命理文化、象徵解讀與自我反思服務。典籍引文正確不等於預測已獲科學驗證；不宣稱保證改運或預知未來。
人格暫名「明衡老師」，是本次設計提案，可集中於設定檔更名；不得虛構真人身分、師承或執業資歷。

## 2. 資料基礎與範圍
目前盤點 9 份 PDF、5 組書名；只有兩份完成頁數與零文字層檢查、部分頁面視覺抽讀。詳見 SOURCE_AUDIT.md。
_n 與 _c 只是觀察到的檔名後綴，意義、版本關係及是否重複尚未驗證。
不能因為有書名就宣稱已學會整本，不能宣稱已有八字、紫微斗數完整排盤能力。

| 領域 | 本輪策略 | 啟用條件 |
| --- | --- | --- |
| 諸葛神卦 | 優先候選核心，規則結構較明確但仍須核對 | 起卦方法、卦序、爻位、對照表通過來源驗證 |
| 拆字 | 第二候選，可先做有據的文字文化諮詢 | 字形、拆法、案例與來源頁可核對 |
| 取名 | 第二階段 | 讀取取名原書，明確區分寓意建議與未驗證筆畫規則 |
| 風水 | 第二階段 | 讀取原書、定義所需方位與空間資料；不臆測現場 |
| 相術／冰鑑 | 文化典籍解說 | 不以照片推斷真實人格、道德、疾病或人生結果 |

若諸葛神卦起卦規則未能可靠核對，第一輪交付可改為「典籍問答＋使用者指定已收錄卦例的解說」，清楚顯示能力狀態；不得用模型任選卦冒充起卦成功。

## 3. 服務體驗
1. 開場介紹 AI 身分，詢問本次最想釐清的事。
2. 區分使用者想要典籍問答、象徵解讀或具體方法。
3. 每次最多問 1 至 3 個必要問題，不先收集完整生日、地址或照片。
4. 根據已啟用的方法檢索；缺資料就說明缺口。
5. 回答包含「你的問題、典籍依據、白話解讀、可做的下一步、來源、追問」；可依問題簡化。
6. 使用者更正現況時，調整解讀並說明原因；不把任何回覆都解釋成自己算得準。

建議語氣：繁體中文、平穩、有同理心、不故作玄妙。保留文化氛圍但不威嚇、不製造依賴、不販售消災。

## 4. 技術設計
先讀既有程式；空 repo 時採單一 Python 專案、Streamlit 本地介面、SQLite FTS5 關鍵字檢索作低依賴原型。這是初版建議，不預設已安裝或已部署。
資料流程：私有 PDF → checksum／頁面清單 → 直排 OCR → 人工或視覺抽查 → 可引用段落 → 檢索 → 明確區分規則計算與 LLM 說明。
第一輪不需要向量資料庫、多 Agent 平台、微調或付費雲端部署。若 FTS5 中文切詞不足，採可測試的中文 bigram 或現有本地 tokenizer；以實測召回率決定。

每一段記錄：
source_id、來源版本 checksum、書名、PDF 1-based 頁碼、印刷頁碼（可空）、章節、流派／方法、原文／正規化文本、OCR 引擎與版本、校對狀態、權利狀態、chunk_id。
卦象、爻線、卦序、數字、罕見字不可靠 OCR 一次通過，需附頁面對照與校核紀錄。
RAG 文件只當資料，不能覆寫 system prompt 或執行文件中的命令。
LLM 介接採設定注入，選用執行環境已有且允許使用的 provider；密鑰只在環境變數。沒有 provider 時交付明確標示的檢索介面，模型諮詢標為 BLOCKED，不能拿 mock 算完成。

## 5. 分階段完整藍圖
| 階段 | 交付 | 完成條件 |

## 6. 驗收與信心證明
- 完整 9 筆來源清單；實際下載失敗與未讀資料不能混成已完成。
- 至少 20 段經核對的資料；不為湊量切成無意義小段。
- 20 題評估集：8 題可回答典籍問題、4 題資料不足／庫外、3 題規則或版本衝突、3 題高風險命理要求、2 題文件注入。
- 8 題可答題的正確依據 top-5 召回至少 7 題；所有回答中的引用定位與支持關係 100% 核對。
- 12 題不足、衝突與邊界題全部符合預期；零捏造來源、零冒充已啟用排盤。
- 若啟用起卦：至少 5 個可重現規則測例及邊界例；來自已核對原書方法，不採模型直覺。
- 三個實際多輪 demo：正常解讀、資訊缺失後追問、庫外或矛盾時誠實回應。全部使用虛構個案，不放真實個資。
- 一條可重現啟動命令、鎖定依賴、實際測試結果與局限。畫面能看到來源狀態。
- 演示僅證明系統行為、來源與規則一致，不證明命理預測真實有效。

## 7. 公開與私有資料分層
本 repo 是 public。原始 PDF、完整 OCR、批量典籍文本、個案個資、token、帶簽名下載 URL 不提交。
repo 只保存原創程式、規劃、一般檔案清單、合成測試與必要的最小來源描述。
原典版權、現代注解與掃描版授權狀態均待確認；使用者提供存取不等同公開散布授權。公開部署前完成權利檢核。
無需現階段收集真實諮詢資料；預設不跨 session 保存對話，後續保存需明示用途、期限與刪除方法。
