## 對實作的影響
1. 優先處理直排繁體 OCR、頁碼對照和圖形卦象，不能直接把 PDF 丟入文字檢索就宣告完成。
2. 卦序與流派應遵循本書；不可把不同系統的通用卦序直接套進本書「第三卦」。
3. 原註、作者釋文、AI 詮釋必須分層；來源的命理斷語不能改寫成客觀保證。
4. 版本比對以 checksum、頁數、抽樣內容、清晰度判定；不憑字尾推定彩色／黑白或完整版。
5. 全庫入庫是一個後續工作；本輪允許先以一個方法的校對子集建立可驗證閉環。
